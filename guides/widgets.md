# 系统小组件

[返回首页](../README.md)

小组件直接读取你连接的 MoviePilot 实例，支持服务概览、下载状态、近期入库和各类订阅。数据不经过通知服务中心；只读展示，不会自动下载、删除或修改订阅。

## 启用与添加

1. 更新 MoviePilot 实例及前端，登录 App。在右上角的 **连接与显示 → 小组件** 中，启用当前服务。
2. 长按 iPhone 主屏幕空白处，进入编辑模式，添加 **MoviePilot**，选择尺寸。
3. 长按已添加的小组件，选择 **编辑小组件**，设置 **服务** 和 **内容**。每个组件可单独选择，系统不会自动绑定某个账号。
4. 锁屏可在系统墙纸编辑界面添加 **MoviePilot 状态**；今天视图也可添加桌面组件。

默认隐藏媒体名称，可在组件编辑器内自行打开。多实例分别启用并选择，组件不会自动切换到 App 当前查看的服务。

| 尺寸 | 展示内容 |
| --- | --- |
| 桌面小尺寸 | 下载状态优先显示上传、下载速度；其他内容显示主要指标 |
| 桌面中、大尺寸 | 下载与上传速度、剩余磁盘空间；空间允许时增加任务进度。其他内容显示概览或有限摘要 |
| 锁屏行内、圆形 | 下载与上传速度；其他内容显示主要指标，不显示媒体名称 |
| 锁屏矩形 | 两行显示双向速度、剩余空间；其他内容显示精简摘要 |

全局速度与磁盘空间沿用仪表盘的管理员权限。普通用户只显示本人下载任务与数量。未知剩余空间显示“—”，真实满盘显示 `0 B`。

锁屏省略服务名和时间，速率采用紧凑写法，例如 `2.4 MB/s` 显示为 `2.4M/s`，数值不变；桌面仍显示完整单位和采样时间。

查看[各尺寸与系统外观截图](../screenshots/README.md#小组件)。

## 刷新、移除与安装

刷新时间由 iOS 调度，不能保证每分钟更新；App 设置中可手动刷新。离线可暂用尚未过期的数据，桌面保留原采样时间；数据最多保留 24 小时。授权有效期为 30 天，到期后在 App 中续期。退出账号、移除资料或失去权限后，组件会清除内容，需重新启用和配置。

自签安装时，保留 IPA 中的 **MoviePilotWidgets 扩展**，并让安装工具同时重签主 App、扩展和共享组。不要选择移除扩展或共享权限。若共享权限缺失，App 的小组件设置会提示不可用，不会改用主登录凭据或另一个账号的数据。安装步骤见[安装与续签](install.md)。
