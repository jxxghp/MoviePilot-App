# 连接与兼容性

[返回首页](../README.md)

先将实例前端更新至 [3.2.0](https://github.com/jxxghp/MoviePilot-Frontend/releases/tag/v3.2.0) 或更新的兼容版本，再输入手机能够访问的 MoviePilot 地址并登录。密码、OTP 和权限继续使用原 MoviePilot 账户；特殊认证可选择网页登录。同一局域网可使用服务器的私网 IP；手机里的 `localhost` 指向手机自身，连接 Mac 上的前端时应填写 Mac 的局域网地址。访问本地服务时允许 App 的“本地网络”权限。

推荐使用证书有效的 HTTPS。工程仅为本地名称、私网和回环地址配置 HTTP 例外，公网 HTTP 和不受信任证书可能被系统阻止。

连接失败时，登录页与网页恢复页会提示证书、地址解析、超时或服务不可达等具体原因。局域网服务无法连接时，也请在 iPhone 的 **设置 → 隐私与安全性 → 本地网络**中检查 MoviePilot 的权限。

IPv6 地址可使用 `http://[fd00::1234]:3000/` 这样的写法。带 `%en0` 等网卡标识的 IPv6 地址不受网页 URL 支持，请改用实例的 `.local` 主机名或其他可访问地址。

完整原生导航需要兼容的前端。不支持容器桥接的旧前端会保留网页导航；需要自行适配时，见[前端兼容与构建说明](../integration/README.md)。

App 使用玻璃主题和大圆角。“主题定制”以半屏窗口提供浅色、深色、跟随系统及主色选择，默认跟随系统。App 不提供网页附加样式、界面布局和其它材质调节；普通网页与 PWA 保留布局、圆角和玻璃材质设置。各端共用玻璃主题的 iOS 明暗色系。

连接和原生登录页沿用当前实例最近的主题及主色，重新打开仍保留；“跟随系统”会随手机明暗变化。旧网页登录会话失效时自动返回原生登录，特殊认证仍可手动选择“使用网页登录”。
