# 连接与兼容性

[返回首页](../README.md)

先将实例前端更新至 [3.2.0](https://github.com/jxxghp/MoviePilot-Frontend/releases/tag/v3.2.0) 或更新的兼容版本，再输入手机能够访问的 MoviePilot 地址并登录。密码、OTP 和权限继续使用原 MoviePilot 账户，登录统一使用原生表单。尚未初始化的实例请先在浏览器创建管理员，再回到 App 连接。同一局域网可使用服务器的私网 IP；手机里的 `localhost` 指向手机自身，连接 Mac 上的前端时应填写 Mac 的局域网地址。访问本地服务时允许 App 的“本地网络”权限。

推荐使用证书有效的 HTTPS。工程仅为本地名称、私网和回环地址配置 HTTP 例外，公网 HTTP 和不受信任证书可能被系统阻止。

连接失败时，原生登录页与恢复页会提示证书、地址解析、超时或服务不可达等具体原因。局域网服务无法连接时，也请在 iPhone 的 **设置 → 隐私与安全性 → 本地网络**中检查 MoviePilot 的权限。

IPv6 地址可使用 `http://[fd00::1234]:3000/` 这样的写法。带 `%en0` 等网卡标识的 IPv6 地址不受网页 URL 支持，请改用实例的 `.local` 主机名或其他可访问地址。

App 需要兼容的前端。旧前端或导航桥接故障会显示原生恢复页，可重新打开或更改服务地址，不会退回完整网页；需要自行适配时，见[前端兼容与构建说明](../integration/README.md)。

App 使用玻璃主题和大圆角。“主题定制”以半屏窗口提供浅色、深色、跟随系统及主色选择，默认跟随系统。App 不提供网页附加样式、界面布局和其它材质调节；普通网页与 PWA 保留布局、圆角和玻璃材质设置。各端共用玻璃主题的 iOS 明暗色系。

当前主题为浅色时，各端均停用全局壁纸并隐藏壁纸设置；切回深色后恢复已选配置。深色主题下保存壁纸来源或地址后立即生效，无需刷新页面。

连接和原生登录页沿用当前实例最近的主题及主色，重新打开仍保留；“跟随系统”会随手机明暗变化。运行中接口返回 401 后直接回到原生登录，无需重开 App；通知连接中断或 App 回到前台时，会检查当前会话并在临时断网时重试。普通网络超时和权限拒绝（403）不退出登录。App 不提供网页登录或网页导航切换入口。

冷启动先显示启动屏并验证已保存的会话，成功后直接进入首页；需要重新登录时才展示表单。

App 复用系统网页资源缓存；兼容前端的内置推荐榜单还提供 60 秒内存快照，推荐页和分页列表可共享已读内容。快照过期后重新请求，离线失败可重试；进入后台、退出登录或权限变化时清理，不在磁盘保存榜单数据。

媒体详情的“在线播放”沿用网页生成的播放器链接，由系统打开已安装的对应 App；网页播放地址使用独立浏览器。日志、种子等文件下载完成后打开系统分享面板，可存储到“文件”或交给其它 App，原页面和弹窗保持可用。

智能助手沿用网页的图片、文件和语音消息。附件通过系统选择器添加，收到的音频可直接播放，文件可下载后分享。录音需允许麦克风权限并使用 HTTPS 安全连接；关闭助手或切到后台会取消尚未发送的录音并释放麦克风。
