## 实施决定

- 直接扩展真实 NativeFormControl 枚举和共享保存计划，新增 `.cron`，不创建 WebView、网页桥或 JS 执行器。配置仍属于同一 NativePluginForm/NativeSession/物理 ID。
- 原生字段可直接输入完整表达式，或打开原生计划弹层；弹层复用 Rex 渐变/玻璃分组、系统导航/输入/选择控件，按 swiftui-liquid-glass 技能复核。只有一套 Rex 风格。
- 可视化提供分钟、小时、日期、月份、星期五个字段，各有全部/指定值/范围/间隔/自定义；常用计划是显式操作。星期生成 mon–sun 名称，避免 APScheduler 3 的数字 0=周一和某些传统 cron 0=周日的歧义。已有数字表达式不自动改写。
- 五个字段在共享玻璃分组中用显式按钮推入对应原生页面，避免同一 Form 行内多个 NavigationLink 的整行联动。模式使用同风格可滚动原生选择页，不依赖在最大字号横屏下会溢出视口的弹出菜单；每个字段草稿按单位隔离。
- 保留原始输入与类型：不编辑不变化，打开/取消/原样应用不得把 nil/null/数字/空值改成字符串或默认表达式；修改后才按原有文本输入语义写字符串。清除沿用输入控件 null 语义，不因显示默认提示就保存 `* * * * *`。
- 五段分析仅服务编辑器：原生构造器输出有界合法字段，无法解释的自定义字符串继续原样输入/保存并明确按插件规则处理。不能把统一 Cron 校验强加给旧插件，或根据手机时区虚构下一次执行时间。执行时区与最终调度解释由服务端/插件决定。
- 可视化弹层是独立草稿；应用才更新父表单，取消不产生父草稿修改。应用到父表单仍不发请求，只有原页面“保存”才 PUT。非文本结构值和未实现行为属性照常阻断；默认未渲染验证器不开放。
- 将原先“隐藏 Cron”未知能力夹具保留并增加真正未实现的编辑器节点，使它在 Cron 支持后仍验证未知能力门禁；不继续把已经实现的 Cron 冒称未知。
