# P2.2b 原生插件配置 UI

本轮从 `3d166f0` 实施 P2.2b.1：常用配置组件、受限条件、实际原生编辑/校验/保存及管理员的已安装插件入口。它是完整 P2.2 的一个可验收功能片，不减少后续组件、表达式、脚本、槽与全生态覆盖要求。

## 已核对的输入

2026-11-20 四仓引用仍为 App origin/main `682e9532`、Frontend origin/v3 `db17d9cb`、Backend origin/v3 `63d09b1c`、Plugins origin/main `5d473864`。只读固定 Git 对象，不使用插件仓脏文件。扫描 get_form AST 发现常见 VCol/VRow、VSwitch、VTextField、VSelect、VTextarea、VAlert；VCronField、自定义编辑器、动作和复杂槽仍是单独能力。

首个完整代表为 MediaDirWatcher 的实际 get_form：开关、两组选择、数字输入、通知用户、目录多行与信息提示。来源样例仅作为回环服务的可重放配置，不导入/运行插件，也不伪称生产运行验收。

## 本轮实施决定

- 管理员从真实原生账号页进入已安装插件清单，再打开同一会话/物理实例的配置。GET plugin/ 使用 state=installed、保留部署前缀/尾斜杠；列表和表单直接访问后端。不是插件市场/安装全功能的完成声明。
- Foundation 计划器把当前原始文档和完整草稿转换成受支持的明确控件枚举，SwiftUI 必须穷尽渲染这些枚举；同一计划器作为保存校验器。未知组件、行为属性、脚本/HTML/槽不静默跳过或返回空校验成功。
- 首轮控件：原生布局分组、开关/复选框、普通/密码/数字文本、TextEditor、多/单选、信息提示、纯文本与分隔。VRow/VCol 在 iPhone/iPad 的阅读宽度内重排为原生分组，保留顺序及全部字段；不复制桌面 CSS 列宽。
- model/v-model/modelvalue 与值类命名绑定保留完整原始键；普通属性的隐式读取和 {{表达式}} 按当前草稿重新解析。数字输入编辑后保留原 Vuetify 字符串输入语义；未编辑数值与未知字段保持原始词法。选择值保留类型，缺失选项不自动丢弃已保存值。
- 原生条件仅执行有界数据表达式：字段/成员/长度、字面量、括号、逻辑/比较；不使用 JavaScriptCore、eval、DOM 或网络。无法表示的语法整体阻止保存；不能借有限语法减少最终兼容目标。v-if 继续按旧 FormRender 的普通未执行属性处理，不擅自变成条件。
- 未知能力的诊断与可见性分开：即使父条件当前隐藏，未知行为也不能遗漏；隐藏字段继续保留。不以局部可见 UI 合成缩减模型保存。
- 页面采用既有 CinematicBackground/Panel/FormRow/PrimaryAction，固定 Rex 渐变、玻璃表面和深色；内容用 Material，成组动作按 swiftui-liquid-glass 技能与当前 Apple 官方 API 使用 Liquid Glass。选择器/错误/空态/进度使用同套组件，不新增主题。
- UI 生命周期结束关闭其表单所有者；选择弹层不能误关闭父表单。会话/账号/实例变化退出旧导航。错误保留草稿，保存成功通知用户并允许返回后刷新插件清单；未确认失败不自动重放。

## 本轮验收

先运行纯计划/表达式/绑定/类型/诊断/校验的边界测试；再批量编译，在 API-only 服务上通过真实账号入口→插件清单→编辑/选择→保存→再次读取，检查完整模型、物理目标与请求计数。补失败保留/重试、未知配置不能 PUT、会话过期/切换、大字/横屏和 iPad，并与 Rex 表单参考并排检查。模拟器结果不替代生产/真机/最低系统/完整 VoiceOver。

当前界面只从 DEBUG --native-v2 路径进入，默认 1.x 不切换。回滚移除本轮渲染/入口，既有底座与草稿仍可独立测试。P2.2b.2 继续 Cron/复杂输入、完整规则与更广表达式/槽；脚本/HTML 与既有 Web 插件仍按 P2.4/P2.5 和最终覆盖门禁处理。

## 实际支持边界

| 能力 | 本轮实现 | 继续保留的门槛 |
| --- | --- | --- |
| VForm/VContainer/VRow/VCol/VCard/VCardText/div | 按源码顺序重排；行/卡形成玻璃分组，统一阅读宽度；常见间距/字体类映射至原生设计规范 | 任意 CSS/style、自定义隐藏类、布局绑定不能静默接受 |
| VSwitch/VCheckbox/VCheckboxBtn | 原生布尔开关、完整字段键、disabled/readonly、标签/说明 | 自定义 true/false 值与复杂控件规则 |
| VTextField/VTextarea | TextField/SecureField/TextEditor；文本/密码/数字、提示/后缀、清除、必填/长度和精确 min/max | 其它输入类型、规则脚本、显式数值 step（any 除外）、Cron/自定义编辑器 |
| VSelect | 原生单/多选弹层，标量或 title/value 对象、可选 item-title/item-value、清除；原始类型/旧未知值保留 | 自定义选项 props/slots、return-object、自动完成/组合输入 |
| 展示 | VAlert、纯文本、分隔；同风格加载/失败/成功/空态 | HTML、复杂展示组件与数据页组件 |
| 条件 | 有界只读字段/静态成员、长度、括号、!、&&/\|\|、关系/严格与宽松标量比较、三元；保留短路 | 函数/方法调用、动态索引、算术、赋值、脚本/任意 JS；完整表达式兼容仍需后续方案 |
| 保存 | 同一 NativeFormPlan 被 UI 与 NativeFormValidator 使用；所有待实现能力阻断完整 PUT | 不能按支持字段过滤后提交；隐藏未知节点也阻断 |

上述是本叶子的真实控件支持度，不是整个 Vuetify 或生态已兼容的声明。原有 get_form 样例保持整体，未改写官方配置来适配控件。辅助合成表单单独声明，用来覆盖条件、多选、秘密输入、隐藏 Cron 和未来字段。

输入类型遇到旧协议的隐式属性读取冲突时，无法确认的 type 返回 unsupported，不回退 TextField 展示值。测试覆盖 type=password 被同名模型字符串或布尔替换的情形。未知/隐藏值仍留在完整草稿，停用保存不能变成删除这些字段的理由。

十进制比较不经 Double，避免保存大整数时静默舍入。它是明确的 JSON 数值语义；极端指数/无法转换的标量与对象引用比较会产生能力诊断，不声称复制 JS Number 的全部浮点边界。字符串键与选项值按原始 Unicode 序列区分。

## 当前入口与重放

真实入口：DEBUG `--native-v2` → 登录管理员 → 账号与服务 → 插件 → 已安装记录 → 配置。普通账号没有配置入口；会话失效/账号或代次变化退出旧导航。列表暂用系统插件符号，插件市场、安装/克隆/日志和受控图片加载属于 P7.1；媒体页的海报要求继续 P3，不在配置表单中添加无意义海报。

回环服务使用 `scripts/native-v2-plugin-ui-fixture.py`（与入口夹具同端口 5330）；它复用实际原生登录/会话请求，官方表单加明确合成的未来字段与物理分身。服务端独立记录完整 PUT/请求数，拒绝错误 state 查询、源插件替代目标、缺字段、跨实例令牌、普通用户与全部前端/JS 路径。成功回执与固定后端 Response 一致，包含 success/message/data。

这仍是 API-only 合约验收，不代表生产插件初始化后的异步效果、真实后端部署或真机已通过。原生 Web 插件兼容入口继续 P2.4；本轮对 Vue 模式显示待迁移说明，不借此打开主体网页。
