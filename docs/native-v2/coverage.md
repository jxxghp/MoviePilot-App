# 范围与迁移矩阵

范围基线是 [baseline.json](baseline.json) 固定的四仓提交，日期为 2026-11-19。主体按现有实际功能迁移，不以底栏上几个菜单代替全范围。

除下面明确列出的原生子流程外，其余仍为“待实施”。合并列举的路由仍各自需要验收；共用同一页面源码不表示权限、参数和状态相同。登录/初始化基础流程完成不等于这些路由的所有认证提供方或配置功能已迁移。

## 组件与弹窗

baseline.json 包含全部 33 个页面文件、90 个通用 dialog 源文件、221 个组件源文件及 31 个 API 模块的路径。90 不是全产品弹层总数：Agent、工作流、卡片内弹层及系统弹窗也要在其功能叶子中核对。

每开始一个功能叶子，补充该功能的操作验收表，字段至少为：

| 字段 | 要记录的事实 |
| --- | --- |
| 来源 | 前端页面/组件/弹窗及固定 SHA，后端方法/路由/schema |
| 动作 | 用户入口、参数、确认、成功、取消、业务失败、HTTP/离线失败 |
| 身份 | 管理员/普通用户、分类权限、功能权限、插件实例/来源 |
| 原生对应 | 原生视图、状态模型、API 与动作处理；不能指向 Web 桥 |
| 证据 | 单元/契约/UI/模拟器/真机各自的执行记录和代码 SHA |
| 剩余 | 待实现、兼容模式、不可验证事项及解除条件 |

不可用一个“页面已完成”复选框代替这张操作表。发现新接口、新弹窗或新插件能力，先登记后续叶子，再评估是否是当前功能的必要部分。

### P2.2b.1 / P2.2b.2a 当前原生子范围

DEBUG v2 的管理员账号入口已经接入已安装插件清单、物理实例配置、原生布尔开关、文本/密码/数字/多行、单多选弹层、提示/分组、有界数据条件、实际值校验和显式完整 PUT。具体组件/属性、固定源码来源、UI/保存共用计划和未支持门禁见 [实施说明](plugin-rendering.md)。它不把 `/plugins` 的市场、安装/更新/卸载/克隆/日志视为完成；这些继续 P7.1。

完整源码代表包括 MediaDirWatcher，以及 LibraryScraper / DoubanRank / RSSSubscribe / AutoClean 的整个 get_form；合成未来字段/物理分身、条件/多选/密码、未知编辑器均单独标识。Cron 已支持保真输入、五字段编辑、预设、取消/应用/清除及完整保存，详见 [Cron 方案](plugin-cron.md) 与 [验收](evidence/2026-11-20-plugin-cron.md)。不能由此推断所有带 Cron 的插件表单均已支持：复杂选择/编辑器/完整规则、任意表达式/脚本/HTML/slots、数据页/仪表板、Web/AppPage 兼容和第三方生态仍待后续叶子。未支持能力不会被过滤后保存，完整草稿也不会因隐藏而丢失字段。主体无 WebView、最低系统、真机与完整辅助功能仍按 P8 总门禁验收。
