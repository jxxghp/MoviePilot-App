## 发现并修正的事项

1. 连续 TextEditor 输入读到上一帧字段快照而丢字。现在绑定直接读取所有者的当前完整草稿；真实键盘快速输入两行目录并在服务端验证每个字符，保存/重读通过。
2. 旧协议会把与模型键同名的属性字符串当作动态值；`type=password` 可能因此变成模型秘密。未知/非字符串输入类型不再回退明文框，直接显示未支持并禁存；新增字符串/布尔冲突测试。合成秘密字段用不冲突的原始键，真正 SecureField 显隐/后台恢复实测。
3. 放弃修改改为原生 alert，两个平台都有明确取消与放弃动作。保持有修改/忙碌时的导航与草稿归属，不把选择弹层打开/关闭误认为退出整个表单。
4. 测试夹具最初缺少标准 `message` 回执字段，客户端正确判为未确认。按固定后端 Response 修复服务端，保留 API 严格契约，并补 HTTP 断言。
5. 测试准备需遍历 Form 延迟创建的合成实例行，删除后固定原始 ID，避免 index 0 重新指向下一行。正文、键盘候选区和原生 sheet 工具栏分别按实际 UI 语义定位，没有坐标点击绕过不可用控件。
