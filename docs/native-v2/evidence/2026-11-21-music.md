# 2026-11-21 原生音乐探索、专辑/艺术家详情与音乐订阅验收记录（P3.5）

## 范围与实现

- 新增 [NativeMusicPage.swift](../../../ios/MoviePilot/NativeV2/Pages/NativeMusicPage.swift)：
  - `NativeMusicPage`：原生音乐探索页，覆盖 `豆瓣音乐`（`GET /api/v1/recommend/music_douban`）、`本周榜单`（`GET /api/v1/recommend/music_weekly`）、`热门专辑` 与 `近期新发`（`GET /api/v1/music/explore`），采用 1:1 方形封面透色玻璃网格（iPhone 2 列 / iPad 4 列）、关键字检索与下拉刷新。
  - `NativeMusicAlbumDetailPage`：直连 `GET /api/v1/music/album/{id}` 与 `POST /api/v1/media/status`，呈现 1:1 居中封面、艺人跳转、年份/发行类型/曲目数徽标、受 `subscribe` 权限门控的「订阅专辑」单次提交与二次确认取消，以及完整分组曲目列表。
  - `NativeMusicArtistDetailPage`：并发读取 `GET /api/v1/music/artist/{id}` 与 `GET /api/v1/music/artist/{id}/albums`，呈现圆形艺人头像、地区与活跃年代、简介及专辑作品网格。
- 更新 [NativeV2MainShell.swift](../../../ios/MoviePilot/NativeV2/NativeV2MainShell.swift)：
  - 在「我的 -> 媒体工作台」与发现页悬浮快捷菜单同步接入受 `discovery` 权限门控的「音乐发现」入口。
