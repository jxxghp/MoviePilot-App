## P1.2b：代次、任务归属与现有安全存储

起点为 087037b。新增 NativeSessionManager、NativeSession 和原生状态模型；协调器通过 Combine 发布不含 credential 的 UI 快照，实例、用户与 generation 保持独立。

新增/确认的边界：

- 初始化确认前不读取保存令牌；原初始化/恢复/登录的迟到结果，即使底层忽略取消，也不能改变新身份或存储。
- A→B→A 保留各自 UUID 的保存记录；同实例重登取得新 generation。已取消的调用不会结束当前活动会话。
- 注销先撤销内存句柄，401 只清理对应当前代次，403/离线不误删令牌。
- 请求、网络返回和确认后分别核对权限；新用户或来源不符不能悄悄替换当前身份。
- 保持登录关闭必须清理旧令牌；清理/保存失败明确拒绝交付新会话，不能让新账号背后保留旧账号自动登录。
- 现有 TokenStore 仅增加协议遵循与 import。移除这两处声明后，方法、Keychain service、UUID account 和属性与父提交逐字相同。SavedInstance 的原 UUID/地址仅增加原生映射，未重写存储格式。
- ios/project.yml 与生成工程加入 MoviePilotSession 产品；默认 SceneDelegate 及旧 UI 未切换。

审阅发现同代次的两次权限刷新也可能乱序。新增回归先复现：旧成功重新打开已撤销权限，或旧 401 删除新确认后的令牌，两个参数场景共 5 个断言失败。修复为独立的用户刷新请求代次后，旧成功/旧 401 都返回 superseded，当前权限和保存记录不受影响。没有改变测试预期或放宽授权。
