# MoviePilot-App v2 界面图册

以下全部 60 张截图采集自 iPhone 17（iOS 26 模拟器）真实运行界面，展示全原生 SwiftUI v2 客户端（零主流程 WebView）的 4+1 Liquid Glass 导航、玻璃弹层、原生图表与完整业务交互。

特别说明：UI设计风格参考了 [Rex iOS App](https://rexnow.tv)。
